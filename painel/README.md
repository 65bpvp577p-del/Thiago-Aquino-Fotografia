# Protótipo do painel de atendimento

Abra `painel/index.html` em um servidor HTTP local. A interface apresenta registros **fictícios**, filtro por status, indicadores e detalhes. Nenhum registro real é carregado ou salvo.

**Não é painel de produção.** Falta autenticação, autorização, conexão com a API administrativa, atualização de status no servidor, agenda com prevenção de conflitos e proteção de dados pessoais. Não utilizar dados reais nesta demonstração.
